# GrapheneUI

This is a in house high performance GUI framework written by SY .

# Usage

In the root folder type,

- This will create required file and folders and a basic demo template..
python Graphene/Bin/graphene.py init

- This will run required file and folders
python Graphene/Bin/graphene.py run

- To run demo code
python Graphene/Bin/graphene.py init
python Graphene/Bin/graphene.py run


- Platforms supported :
- Linux    (fully supported)
- Windows  (not yet, but will be soon)
- Android  (not yet, but will be soon)
- IOS      (not yet, but will be soon)
- Mac      (not yet, but will be soon)
- Web      (not yet, but will be soon)
